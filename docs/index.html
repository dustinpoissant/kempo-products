Kempo Products

GitHub npm

A product catalog for kempo. Show what you sell or have on offer, let people browse, filter and search it, and add a way to buy later.

Pre-release: not on npm yet.

It works on its own. A dealership can list its cars with no checkout at all, and a shop can add a checkout later to sell the same catalog online. Nothing here depends on an inventory system, though a connector joins the two when you use both.

What it does

  • Types and fields you build in the admin. Make a "Vehicle" with make, model and year, or a "Model car" with a scale and a brand, without writing code.
  • Options with relative prices. One base price, and each choice adds to it or takes from it: "no clear coat, -1.00". No typing a full price for every combination.
  • Public pages that need no setup. A searchable, filterable list at /products/ and a page for each product, with its options kept in the address so a link opens with the same choices.
  • Components for your own pages. A few hand-picked products on the home page is one line of HTML.
  • Optional everything else. Prices, stock and images are all optional, so a catalog that is only a showcase stays simple.
  • A purchase hook other extensions build on. Whoever takes the orders records a purchase; products takes the stock and tells everything that cares.

Quick start

1. Install the package

In your kempo site:

npm install kempo-products

2. Install the extension

Open Admin > Extensions and install kempo-products. A Products entry appears in the admin menu.

3. Add a product

Give it a name, set it to Published, and save. It is now public at /products/.

The Products page in the admin. Everything about the catalog is managed from here.
What visitors see at /products/, with no setup.

4. Show some on your home page

Add this where you want them:

<script type="module" src="/products/components/ProductList.js"></script>
<k-prod-list tag="featured" limit="4" hide-controls no-url></k-prod-list>

Tag a few products featured and they appear. The components page covers every way of choosing products.

Works with

ExtensionHow
kempo-mediaOptional. When it is installed, products get pictures. Without it the field is simply not shown.
kempo-inventoryTracks raw materials and stock. Not needed by products, but see the connector.
kempo-products-inventoryThe connector. Requires both of the above: selling a product takes its materials out of inventory.
kempo-commercePlanned. Cart, orders and checkout, built on this catalog.
