# kempo-products

A product catalog for [kempo](https://github.com/dustinpoissant/kempo). Show what you sell or have on offer, let people browse, filter and inquire, and add a way to buy later.

**Status: design only.** Nothing is built yet. Read [PLAN.md](PLAN.md) for what this will be and how it is being designed.

It works on its own. A dealership can list its cars and take inquiries without any checkout, and a shop can add `kempo-commerce` later to sell the same catalog online.
