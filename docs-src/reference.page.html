HTTP API

JSON routes under /products/api/. Reads are public: they return published products only, with no exact stock count, no owner details, and no prices when prices_visible is off. Everything that changes something needs the permission shown.

RoutePermissionPurpose
GET confignoneThe currency, whether prices show, whether images are available, and the allowed values
GET productsnoneList and search. Parameters are on the Components page
GET products/<id or slug>noneOne product, with its options, the fields of its type, and its images
POST productsproducts:createCreate a product
PATCH products/<id>products:updateChange a product. Only what is sent changes
DELETE products/<id>products:deleteDelete a product
GET price?product=&options=noneThe server's price for a set of choices. options is JSON: {"color":"gold"}
GET types, GET fieldsnoneThe types and fields. fields?type=model-car gives what a product of that type shows
POST, PATCH, DELETE on types and fieldsproducts:types:manageManage types and fields
GET purchasesproducts:readRecorded purchases
POST purchases, POST purchases/<ref>/reverseproducts:purchases:recordRecord a sale made elsewhere, and reverse one
GET export?format=csv|jsonproducts:readDownload the catalog
POST importproducts:create and products:updateImport a file: { content, onMatch, dryRun }

A person who holds products:read also sees drafts, archived products and exact stock from the read routes. The same calls are available in the browser as the SDK at /products/sdk.js.

Permissions and groups

PermissionAllows
products:readSee drafts and archived products, exact stock, and purchases in the admin
products:create, products:update, products:deleteManage products
products:types:manageCreate, edit and delete types and fields
products:purchases:recordRecord a purchase made elsewhere, and reverse one

Published products need no permission to see. Three groups are provided, each of which also lets its members into the admin:

GroupCan
kempo-products:viewerSee everything in the catalog, including drafts, but not change it
kempo-products:managerAdd, edit and delete products, and record purchases
kempo-products:adminEverything a manager can, and set up types and fields

Settings

Under Admin > Settings.

SettingDefaultMeaning
currencyusdThe three-letter currency code prices are shown in, such as eur or gbp
prices_visibletrueShow prices to visitors. Turn off to run a catalog that never shows what things cost
page_size24Products per page on the public list

Money

Money is always a whole number of the currency's smallest unit: 4999 is $49.99. This is so there is never a rounding error, and it is the same convention kempo-payments uses. The number of decimal places depends on the currency: two for most, none for currencies such as the yen (500 is 500 yen), and three for currencies such as the Kuwaiti dinar.

import { parseMoney, formatMoney, displayMoney } from 'kempo-products/sdk';

parseMoney('49.99');                // [null, 4999]
parseMoney('-1.00');                // [null, -100]   (an option's adjustment)
parseMoney('1.999');                // [error, null]  (never rounded silently)
formatMoney(4999);                  // '49.99'
displayMoney(4999, 'usd');          // '$49.99'

Development

npm run link:local          # symlinks the sibling kempo checkouts
docker compose up -d        # a throwaway Postgres on port 5443
export DATABASE_URL=postgresql://kempo:kempo@localhost:5443/kempo_products_test
npx drizzle-kit push --force
npm test

The database tests skip themselves when no database is reachable, and refuse to run unless its name ends in _test, because they empty the tables. A green run with SKIPPED did not test the database.
